# Claude Code / Beam

- Leer AGENTS.md antes de actuar.
- Para tareas pequeñas, usar lectura directa y herramientas mínimas.
- No usar subagentes automáticamente.
- No usar `--fix` global ni `eslint-disable`.
- No instalar dependencias sin autorización.
- Revisar el diff de la tarea antes de finalizar.
- Preservar cambios preexistentes.
- Detenerse ante diffs inesperados.
- No ejecutar comandos destructivos.
- No afirmar validaciones no ejecutadas realmente.
- Mantener respuestas y reportes compactos para reducir consumo de contexto.
